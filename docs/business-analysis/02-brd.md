# Business Requirements Document (BRD) — Global Supply Chain & Logistics Intelligence

| Req ID | Requirement Description | Priority |
| :--- | :--- | :--- |
| `BR-001` | Star schema warehouse containing 5,000 multi-modal shipments across Date, Route, Carrier, Category, and Weather dimensions. | High |
| `BR-002` | Executive KPI tiles with dynamic Insight Summary cards reconciled directly to filtered metrics. | High |
| `BR-003` | Weather disruption breakdown and high-risk shipment gauge (`Risk Index >= 95th/threshold`). | High |
| `BR-004` | Multi-dimensional volume charts by Transport Mode, Product Category, and Region. | Medium |
| `BR-005` | Ranked Top High-Risk Routes table and Most Critical Route spotlight (`Rotterdam → Marseille`). | High |
| `BR-006` | Seven interactive slicers (`Year`, `Quarter`, `Month`, `Origin Port`, `Transport Mode`, `Product Category`, `Weather Condition`) plus CSV export. | High |
